# Contributing to launchpad-ops

Thanks for helping out! This project is in its early stages, so here are the ground rules for getting changes in.

## How to contribute

1. Fork or branch off the default branch (`main`) when preparing changes.
2. Create a feature or chore branch using the conventions `feat/`, `fix/`, `docs/`, or `chore/`.
3. Make your changes with clear, focused commits.
4. Open a pull request into `main` describing what changed and why.
5. Reference any related issue (for example, the Release readiness epic) from the pull request description.

## Code of conduct

- Keep discussions respectful and on topic.
- Reviews are advisory by default unless changes are explicitly requested.
- Small, reviewable changes are preferred over large batches.

## Reporting bugs and requesting features

Open an issue with enough context to reproduce the problem, including expected vs. actual behavior.

## Release process

Releases are cut from `main` once the release readiness epic has all of its sub-issues completed.
